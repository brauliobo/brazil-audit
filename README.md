# Legendas, vagas e vínculos declarados

Fatos das fontes arquivadas do TSE, incluindo partidos, coligações e federações. Ano/turno/data/cargo e jurisdição são preservados. Uma referência de contexto sem election_id não equivale a um pleito identificado. Vagas declaradas não representam eleitos observados nem uma simulação de cadeiras. Vínculos de candidato conservam a sequência da fonte; uma identidade não comprovada permanece NULL.
