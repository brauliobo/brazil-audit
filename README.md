# Perfis históricos de eleitorado e comparecimento

Células demográficas oficiais completas, normalizadas para consultas SQL no navegador. Cada ZIP contém os CSVs gzip e o índice com campos, fonte original e SHA256.

O nível state soma células territoriais disjuntas conservando todas as dimensões; detail conserva município/zona da fonte. Nunca some os dois níveis. Eleitorado é um retrato cadastral por ano da fonte, não o eleitorado de qualquer pleito suplementar. Comparecimento conserva somente os turnos efetivamente informados. Códigos demográficos negativos e rótulos originais permanecem; medidas ausentes são NULL.

Fonte e licença: https://dadosabertos.tse.jus.br (CC BY). ARCHIVE.json e SHA256SUMS verificam todos os arquivos publicados.
